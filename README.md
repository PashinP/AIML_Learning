## ⚡ How to Navigate This Repo

<details>
<summary><b>Click to expand tips for reviewing projects</b></summary>
<br>

1. **Jupyter Notebooks**: Most of the heavy lifting and data analysis is done in `.ipynb` files. They include detailed markdown cells explaining the "why" and "how".
2. **Datasets**: Accompanying CSVs (e.g., `shop_smart_ecommerce.csv`, `novagen_dataset.csv`) are provided for reproducibility.
3. **Model Weights**: Best trained deep learning models (like `best_model.pt`) are included so you don't have to retrain from scratch.
